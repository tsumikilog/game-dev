# Roblox MVP Spec

## コンセプト

短時間で遊べる収集型ミニゲーム。
プレイヤーはフィールド内に出現するアイテムを集め、制限時間内のスコアを伸ばす。

## 狙い

- Roblox開発の基本フローを覚える
- Rojo + Git + AI実装の型を作る
- 制作ログをX/Brain教材に転用できる状態にする

## 最小ゲームループ

1. ゲーム開始
2. フィールドにアイテムが出現
3. プレイヤーがアイテムを拾う
4. スコアが増える
5. 60秒経過で終了
6. 最終スコアを表示

## 初期スコープ

- マップ: 小さな平面フィールド
- アイテム: 1種類
- スコア: 数値のみ
- 制限時間: 60秒
- マルチプレイ: Roblox標準の同時参加を前提に、ランキング等は後回し

## 後回し

- 課金
- ガチャ
- 複雑な敵AI
- ステージ制
- CryptoNinja固有キャラクターの反映
- 公開/収益化
